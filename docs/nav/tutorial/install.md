# Install

## Requirements

- Python 3.10+

## Install with pip

```bash
pip install email-profile
```

## Install with Poetry

```bash
poetry add email-profile
```

## With the MCP server

Adds the `email-profile-mcp` command for Claude Code, Claude Desktop and
Cursor — see [MCP Server](../advanced/mcp-server.md).

```bash
pip install "email-profile[mcp]"
```
